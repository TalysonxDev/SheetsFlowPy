SheetsFlowPy

Automação de planilhas de fluxo desenvolvida em Python, com foco na leitura, validação e processamento de dados em múltiplas abas.

Sobre o projeto

O SheetsFlowPy é uma aplicação responsável por ler uma planilha contendo múltiplas abas, realizar a validação dos dados com base em regras definidas e processar automaticamente as informações diretamente em uma planilha já existente.

O sistema percorre automaticamente até 16 abas, aplicando lógica de validação e preenchendo os dados necessários, incluindo informações como status e dia correspondente.

Esta solução foi desenvolvida para auxiliar diretamente em atividades do dia a dia profissional, contribuindo para a automação de processos e aumento de produtividade.

Preenchimento automático de informações (status e datas)
Desenvolvimento

Durante o desenvolvimento, foram utilizadas ferramentas de Inteligência Artificial como suporte para aumento de produtividade e auxílio técnico.

A base do projeto contou com apoio do Claude Code, sendo posteriormente adaptada e evoluída com implementações próprias, aplicando lógica de programação e regras específicas definidas para o processamento dos dados.

Os dados utilizados no projeto foram adaptados e editados para preservar informações sensíveis, não representando dados reais da empresa.

Objetivo

Desenvolver uma solução automatizada para tratamento e validação de dados em planilhas, reduzindo esforço manual e aumentando a eficiência no processamento das informações.
